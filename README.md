# EMWAT-Linux

بازسازی بومی EMWAT برای Linux با حفظ قابلیت‌های نسخه Windows و سازگاری با LibreOffice.

> این مخزن برای توسعه نسخه لینوکسی است. فایل‌های نصب ویندوز صرفاً مرجع تحلیل‌اند و نباید بدون مجوز صاحب اثر بازتوزیع شوند.

## وضعیت فعلی تحلیل

- نام محصول از فراداده نصب‌کننده: **Emwat Service**
- شرکت درج‌شده: **Gamelectronics Co.**
- نسخه فایل: **6.3.7.10251**
- نسخه محصول: **7.3.0.0**
- معماری نصب‌کننده: **PE32 / x86 (32-bit)**
- بسته‌بندی: **Wise Installation Wizard / Wise for Windows Installer**
- سکشن اصلی داده‌های نصب‌کننده: `.WISE` (حدود 16.2 MiB)

### نکته مهم

استخراج اولیه با 7-Zip فقط سکشن‌های فایل PE و منابع نصب‌کننده را بیرون آورده است؛ هنوز فایل‌های واقعی برنامه، سرویس‌ها، پایگاه داده، قالب‌ها و منطق محاسباتی استخراج و بررسی نشده‌اند. بنابراین فناوری پیاده‌سازی برنامه اصلی و قابلیت‌های دقیق آن هنوز تأیید نشده است.

## ساختار پروژه

- `analysis/` گزارش‌ها و یافته‌های مهندسی معکوس
- `docs/` مستندات نیازمندی‌ها و طراحی
- `linux-app/` پیاده‌سازی بومی لینوکس
- `tests/` آزمون‌ها و داده‌های تست غیرمحرمانه

## اصول توسعه

1. نسخه جدید فقط برای Linux است؛ نسخه Windows موجود صرفاً مرجع رفتاری خواهد بود.
2. اجرای برنامه با Wine جزو راهکار نهایی نیست.
3. LibreOffice برای تبادل و کار با اسناد/صفحه‌گسترده‌ها در نظر گرفته می‌شود؛ نوع دقیق اتصال پس از شناسایی گردش‌کار اصلی تعیین خواهد شد.
4. پیش از پیاده‌سازی، قابلیت‌ها، ورودی‌ها، خروجی‌ها، فرمول‌ها و وابستگی‌های نسخه اصلی مستند می‌شوند.
5. فایل‌های اجرایی، داده‌های مشتریان، کلیدها و اطلاعات محرمانه را در مخزن قرار ندهید. برای فایل‌های حجیم یا اختصاصی از فضای خصوصی و مجاز استفاده کنید.

## گام بعدی

محتویات استخراج‌شده از نصب‌کننده Wise باید به‌صورت محلی بررسی شود. پس از شناسایی فایل MSI/CAB یا فایل‌های برنامه، فقط گزارش ساختار و فایل‌های لازم و مجاز به مخزن اضافه می‌شوند.
